## ✉️ Direct Technical Inquiries

For questions about the configuration schema, manifest discovery, or
anything not covered by the README:
Email: `electrohobby3d@gmail.com`

## 🐛 Bug Reports

If `hydra-umc-dev-server config validate` accepts a document it should
reject (or the reverse), or `inventory scan` misses or misreads a real
manifest, please open a **GitHub Issue** in this repository - include the
exact command you ran, the configuration/manifest file involved (with any
real secret redacted first), and its full, real output.
*Please search existing issues before opening a new one.*

## ❌ What is NOT support?

- This is DS01 (contracts, limits and a verifiable skeleton) of a
  10-delivery plan - it cannot yet provision a remote host, run a task,
  queue work durably, or talk to an AI provider. Please do not open an
  Issue asking it to do something a later delivery has not shipped yet;
  see the README's own Roadmap section for what is planned and when.
- This project coordinates other real HYDRA-UMC/URTC projects
  (HYDRA-UMC-OPS-AGENT, HYDRA-UMC-SDK, HYDRA-UMC-UPDATER, etc.) - a real
  bug inside one of THOSE projects' own code belongs on their own issue
  tracker, not this one's.
